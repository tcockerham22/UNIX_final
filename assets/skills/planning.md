# Planning

When Sam asks for a plan:

1. Restate the goal and any constraints in one or two sentences.
2. Identify the smallest useful first step.
3. Break the work into ordered steps with clear outcomes.
4. Call out dependencies, risks, and decisions that need Sam's input.
5. Estimate effort roughly and state the uncertainty.
6. Prefer a simple plan that can start now over an elaborate one that cannot.
7. End with the immediate next action and how to verify progress.
8. Keep the plan short unless Sam asks for full detail.
